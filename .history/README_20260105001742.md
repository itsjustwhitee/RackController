# RackController v2.0: Smart Cooling System (ESP32)

A DIY professional-grade cooling system for home server racks or network cabinets, built with ESP32-S3, Arctic PWM fans, and a DS18B20 temperature sensor.

This version introduces persistent memory for settings, a dynamic web-based curve preview, and a WiFi configuration portal to manage network credentials without reflashing the code.

## 🚀 Features

*   **♨️Automatic Temp Control:** Linear PWM ramp based on temperature.
*   **🤫Zero dB Mode:** Fans completely stop when temperature is below threshold (30°C).
*   **🌙Night Mode:** Automatically limits fan speed (Max 40%) between 23:00 and 07:00 for silence (unless critical temp is reached).
*   **🌐Web Interface (Dark Mode):**
    *   Real-time monitoring (Temp & Fan %).
    *   Manual Speed Offset (+/- 5%).
    *   Timer for manual overrides.
    *   Master Controls (AUTO, MAX, OFF).
    *   Responsive design for Smartphones.
*   **🖥️OLED Display:** Shows live stats, IP address, and automatically dims at night.
*   **❌Offline Mode:** Works autonomously even without a Wi-Fi connection.

** 🚀 New in v2.0

* 📊 **Live Curve Preview**: An interactive chart on the web interface that updates in real-time as you tweak temperature thresholds.
* 💾 **Persistent Storage (Preferences)**: Temperature thresholds and WiFi credentials are saved to the ESP32's Flash memory. Settings survive power outages.
* 📶 **Web WiFi Setup**: Change your SSID and Password directly from the browser. The system reboots and connects to the new network automatically.
* ⚡ **Anti-Stall Logic (PWM Startup)**: Ensures fans always start reliably by applying a minimum "Kickstart" duty cycle (~12%), preventing the motor from humming or stalling at low temperatures.
* ⏲️ **Adjustable Override Timer**: Set how long manual speed offsets stay active before the system reverts to AUTO mode.
* 🔄 **AJAX Real-time Monitoring**: The web dashboard updates every 2 seconds using JSON background requests for a lag-free experience.

## 🛠 Hardware Required (specifically what I used)

*   **Microcontroller:** ESP32-S3 (N8R2 used here, but any ESP32 works).
*   **Fans:** Arctic P14 PRO PWM PST (or P12) or similar (any standard 4-pin PWM fans, at least one for intake and one for exhaust).
*   **Temp Sensor:** DS18B20 (check waterproof probe).
*   **Power:** 12V 2A Power Supply + LM2596 Step-down Module (12V to 5V for ESP32).
*   **Display:** 0.96" OLED I2C (SSD1306).
*   **Misc:** Simil Wago connectors, 20AWG silicone wires, DC Jack adapter, PWM extensions (just not to cut fan and power supply cables).

## 🔌 Wiring

| Component | ESP32 Pin | Note |
| :--- | :--- | :--- |
| **Fan PWM** | GPIO 37 | Blue wire of the fan |
| **DS18B20 Data** | GPIO 4 | Requires 4.7k Pull-up resistor (often built-in on modules) |
| **OLED SDA** | GPIO 1 | I2C Data |
| **OLED SCL** | GPIO 2 | I2C Clock |

*Note: Fans must be powered directly by the 12V PSU. The ESP32 and OLED are powered by 5V (from LM2596). Only grounds (GND) must be shared.*
*Note: almost all GPIO pins are equivalent*

## ❄️ Cooling Logic

The system follows a 3-stage automatic logic to balance silence and performance:

<p align='center'>
   <img width="50%" alt="Graph Example (28°C-35°C-55°C)" src="assets/graph.png" />
   <br/>
   <i>Graph Example (28°C-35°C-55°C)</i>
</p>

1. **🚫 OFF Zone**: Below the `Off to Low` threshold, fans are completely stopped (0% PWM).
2. **▶️ Startup Zone**: Between `Off to Low` and `Ramp Start`, fans run at a fixed **Minimum Startup PWM** (~10%). This ensures the fan has enough torque to spin reliably.
3. **📈Ramp Zone**: Between `Ramp Start` and `Full Speed`, the speed increases linearly from the minimum value to 100%.

**🌙 Night Mode**: Between 23:00 and 07:00, the system automatically limits the fan speed (Max ~40%) to ensure silence in the room.

## 🖥️ OLED Display

The display retains the original high-readability layout:
* **Top Bar**: Shows the current mode (AUTO/MANUAL/MAX/OFF) and the last octet of the local IP address.
* **Center**: Celsius temperature in large digits.
* **Bottom**: A thick progress bar showing fan power percentage.
* **Auto-Dim**: The display automatically reduces contrast during Night Mode to prevent OLED burn-in and light pollution.

## 📦 Installation

1.  **Install Arduino IDE** (Legacy 1.8.x or 2.0+, this could give throubles while downloading).
2.  Install the **ESP32 Board Manager** (by Espressif).
3.  Install required libraries via Library Manager:
    *   `Adafruit SSD1306`
    *   `Adafruit GFX`
    *   `DallasTemperature`
    *   `OneWire`
4.  Open the `.ino` file.
5.  *[Optional]* **Edit lines 52-53** with your Wi-Fi credentials:
    ```cpp
    String s = prefs.getString("ssid", "WIFI-Name");
    String p = prefs.getString("pass", "PASSWORD");
    ```
    *Note: Change also pin numbers if you used different ones.*
6.  Select your board (e.g., `ESP32S3 Dev Module`) and Flash it.

## 📱 Usage

1.  Power on the system.
2.  The OLED will display the (last group of numbers of) IP address (e.g., `45` for `192.168.1.45`), if connected to a WiFi.
3.  Open that IP in your browser.
4.  **Controls:**
    *   ⚡**Speed:** Add/Remove speed percentage relative to the automatic logic.
    *   ⌚**Timer:** Set a duration for your manual offset changes.
    *   👑**Master:** Force MAX speed or turn OFF everything.
    *   ⚙️**Tweak the Curve**: Adjust the curve for your devices and environment (useful especially in different seasons :D)
